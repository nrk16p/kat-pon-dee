# Process 1 — แอปช่วยคัดลำไยลงตระกร้า

แก้ไข 2026-07-30 หลังได้ข้อมูลจากผู้ใช้ว่าแอปต้อง **ช่วยแยก** ไม่ใช่รับรองทีหลัง

---

## 1. ความจริงที่ต้องยอมรับก่อน

> **แอปแข่งความเร็วกับมือคนไม่ได้**

คนคัดลำไยหยิบแล้วตัดสินใจภายในวินาทีเดียว ถ้าออกแบบให้ต้องถ่ายรูปทีละลูก
จะช้ากว่าใช้ตาเปล่าหลายเท่า และไม่มีใครใช้

**แต่ปัญหาจริงของการคัดด้วยมือไม่ใช่ความเร็ว — คือความสม่ำเสมอ**

- คนละคนคัด เส้นแบ่ง AA/A ไม่เท่ากัน
- คนเดิมคัดตอนเช้ากับตอนบ่าย ตาล้าแล้วเส้นเลื่อน
- แสงเปลี่ยน ลำไยดูใหญ่ขึ้น/เล็กลง
- ผู้รับซื้อวัดแล้วไม่ตรง → เถียงกัน

**สิ่งที่แอปทำได้ดีกว่ามือคนคือตรึงเส้นแบ่งให้นิ่ง** ไม่ใช่หยิบเร็วกว่า

ดังนั้น "ช่วยแยก" ควรแปลว่า **ช่วยให้แยกได้ถูก** ไม่ใช่ **ช่วยให้แยกได้เร็ว**

---

## 2. สามวิธีที่แอปช่วยแยกได้จริง

### วิธี A — ตั้งตาก่อนเริ่มงาน (Calibration)

ก่อนเริ่มคัด เทลำไยสัก 40–60 ลูกลงแผ่น ถ่ายรูปเดียว

แอปแสดงภาพพร้อมวงกลมสีตามเกรด + ขนาดจริงทุกลูก **คนคัดเห็นกับตาว่า
28.0 มม. หน้าตาเป็นยังไง** แล้วค่อยไปคัดด้วยมือตามปกติ

- ใช้เวลา ~30 วินาที ต่อกะ
- ไม่ขวางงาน
- แก้ปัญหา "เส้นแบ่งของแต่ละคนไม่เท่ากัน" ได้ตรงจุดที่สุด
- **ของที่ต้องใช้มีครบแล้ว** — ภาพ overlay ที่ทำไปเมื่อวานคือสิ่งนี้พอดี

### วิธี B — โหมดถาดคัด (Sorting tray)

เกลี่ยลำไยลงแผ่นเป็นชั้นเดียว ถ่าย → หน้าจอแสดงวงสีทุกลูก → หยิบลงตระกร้าตามสี

- แม่นที่สุด แต่ช้า
- เหมาะกับ **ลูกที่ก้ำกึ่ง** หรือล็อตราคาสูง ไม่เหมาะกับการคัดทั้งกอง
- ต้องเกลี่ยไม่ให้ซ้อนกัน ซึ่งเป็นงานเพิ่ม

### วิธี C — ตรวจการเลื่อนของเส้นแบ่ง (Drift check) ⭐

ทุก ๆ 5–10 ตระกร้า ตักตัวอย่างจากตระกร้า AA มาเกลี่ยบนแผ่น ถ่ายหนึ่งรูป

> *"ตระกร้า AA นี้ มี AA จริง 78% · A 22% — เส้นแบ่งเริ่มเลื่อน ลำไยเล็กหลุดเข้ามา"*

- ใช้เวลา ~30 วินาที ต่อ 10 ตระกร้า
- **จับปัญหาที่คนมองไม่เห็นด้วยตัวเอง** คือตาล้าแล้วเส้นเลื่อนทีละนิด
- ป้องกันการโดนผู้รับซื้อตีกลับทั้งล็อต

**ผมแนะนำ A + C เป็นหลัก** ทั้งคู่ใช้เวลาน้อย ไม่ขวางการทำงาน และแก้ปัญหา
ที่แพงที่สุดคือของถูกตีกลับ ส่วน B เก็บไว้เป็นทางเลือกสำหรับล็อตพิเศษ

---

## 3. ตัวขวางที่ต้องแก้ก่อน

### 3.1 ตอนนี้ช้าเกินไปสำหรับการคัด

ปัจจุบัน **16–18 วินาทีต่อรูป** บน Render

| วิธี | จำนวนรูป/กะ | 18 วิ | 5 วิ |
|---|---|---|---|
| A ตั้งตา | 1–2 | รับได้ | ดี |
| C ตรวจ drift | 5–10 | เริ่มน่ารำคาญ | รับได้ |
| B ถาดคัด | 50+ | **ใช้ไม่ได้** | พอไหว |

วิธี A กับ C ใช้ได้เลยวันนี้ **แต่ B ต้องรอ Standard instance ก่อน**

สวนมีเน็ต ดังนั้นความช้าทั้งหมดอยู่ที่ CPU ของเซิร์ฟเวอร์ ไม่ใช่สัญญาณ —
อัปเป็น Standard แก้ได้ตรงจุด

### 3.2 ลำไยในตระกร้าซ้อนกัน วัดไม่ได้

ผมวัดไว้แล้ว: วางห่าง 36 มม. วัดได้ 100% · วางชิด 32 มม. เหลือ 72% ·
เทกองซ้อนกัน **เหลือ 2%**

แปลว่า **ถ่ายทั้งตระกร้าตรง ๆ ไม่ได้** ต้องตักตัวอย่างมาเกลี่ยบนแผ่นก่อน
นี่ไม่ใช่ข้อจำกัดชั่วคราว — สิ่งที่มองไม่เห็น วัดไม่ได้

ต้องออกแบบขั้นตอนให้ชัดในแอป ไม่งั้นชาวสวนจะถ่ายทั้งตระกร้าแล้วได้ผลผิด

### 3.3 ยังไม่รู้ว่าวัดลำไยจริงแม่นแค่ไหน

ถ้าเส้นแบ่งของแอปเองคลาด 2 มม. การ "ช่วยแยก" จะทำให้คัดผิดทั้งกะ —
**แย่กว่าปล่อยให้คัดด้วยตาเปล่า** เพราะคนจะเชื่อแอป

## 4. Process 2 — บรรจุกล่อง (แยกจากกันจริง)

เห็นด้วยว่าต้องแยก เพราะ:

| | Process 1 คัดลงตระกร้า | Process 2 ลงกล่อง |
|---|---|---|
| ที่ไหน | ที่สวน | ล้ง / จุดรวบรวม |
| ใครทำ | คนคัด | คนบรรจุ / QC |
| เมื่อไร | ตอนเก็บเกี่ยว | หลังขนส่ง |
| แอปทำอะไร | ช่วยตั้งเส้นแบ่ง + จับ drift | ตรวจซ้ำ + ผูกตระกร้ากับกล่อง |

**สองอย่างนี้ไม่ควรอยู่หน้าจอเดียวกัน** คนละคนใช้ คนละที่ คนละเป้าหมาย

(สวนมีสัญญาณเน็ต จึงไม่ใช่ตัวแบ่งระหว่างสองกระบวนการ — ที่แบ่งคือคนกับเป้าหมาย)

จุดเชื่อมเดียวคือ **รหัสตระกร้า** — ป้าย ArUco ที่ถ่ายติดมาในภาพเดียวกับที่วัด
ทำให้ล้งเปิดดูได้ว่าสวนรับรองตระกร้านี้ไว้ว่าอะไร

---

## 5. ลำดับที่แนะนำ

| ระยะ | ทำอะไร | ใช้ของที่มีแล้ว |
|---|---|---|
| **0** | พิสูจน์ความแม่นกับลำไยจริง | — |
| **1** | **โหมดตั้งตา (A)** | ✅ ภาพ overlay ทำเสร็จแล้ว เหลือแค่จัดหน้าจอ |
| **2** | **โหมดตรวจ drift (C)** | ✅ ใช้การวัดเดิม เพิ่มการเทียบกับเกรดที่ประกาศ |
| **3** | ป้าย ArUco ตระกร้า | ต่อยอดจากตัวอ่านมาร์กเกอร์เดิม |
| **4** | โหมดถาดคัด (B) | ต้องเร็วกว่านี้ก่อน |
| **5** | Process 2 ลงกล่อง | ต้องมีระยะ 3 ก่อน |

**ระยะ 1 กับ 2 ทำได้เร็วมาก** เพราะเครื่องมือมีครบแล้ว ที่ต้องเพิ่มคือ
การจัดหน้าจอกับการเทียบผลกับเกรดที่ตั้งใจไว้ ไม่ใช่ความสามารถใหม่

---

## 6. คำถามที่ยังต้องถามคนคัดจริง

1. ตอนนี้คัดกี่เกรด แยกจริงทุกเกรดหรือแยกแค่ AA กับที่เหลือ?
2. คัดด้วยมือล้วน หรือมีเครื่องคัดขนาด/ตะแกรง?
3. หนึ่งกะคัดกี่กิโล กี่ตระกร้า?
4. เคยโดนผู้รับซื้อตีกลับเพราะเกรดไม่ตรงไหม บ่อยแค่ไหน?
5. ถ้าแอปบอกว่า "ตระกร้านี้เกรดเลื่อนแล้ว" จะทำอะไรต่อ — คัดใหม่ หรือลดราคา?

**ข้อ 4 ตัดสินว่าฟีเจอร์นี้มีมูลค่าจริงไหม** ถ้าไม่เคยโดนตีกลับเลย
การตรวจ drift ก็ไม่มีใครอยากใช้ ถ้าโดนบ่อย นี่คือฟีเจอร์ที่ขายได้
