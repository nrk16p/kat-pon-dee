จะถูกลบทุกครั้งที่ deploy ซึ่งคือชุดข้อมูลที่ใช้เทรนโมเดลในอนาคต

## หลัง deploy เสร็จ

1. Render จะให้ URL แบบ `https://kat-pon-dee-api.onrender.com`
2. ตั้ง `CORS_ORIGINS=https://kat-pon-dee.vercel.app` ใน Render dashboard
3. ตั้ง `VITE_API_URL=https://kat-pon-dee-api.onrender.com` ใน Vercel แล้ว redeploy
4. ปิด cloudflared บนเครื่องได้เลย ไม่ต้องเปิดโน้ตบุ๊กทิ้งไว้อีกต่อไป

## ข้อควรระวัง

- Disk ทำให้ scale เกิน 1 instance ไม่ได้ — ไม่เป็นปัญหาสำหรับตอนนี้
- Build ครั้งแรกนาน 3–5 นาที เพราะ wheel ของ opencv ใหญ่ (~90 MB)
- `region: singapore` ใกล้ไทยที่สุด ลด latency ได้จริง
